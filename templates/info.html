{% elif page=='privacy' %}

How this prototype handles applications

Submitting an application stores your name, email, phone number, experience, message and PDF résumé on the server running this app. Information is intended for recruitment review by the app operator.

Access and retention

Applicant records and uploads are stored privately outside the public website folder. There is no automatic deletion schedule in this prototype. The operator must set a retention period, restrict access and arrange deletion and backups.

Cookies

The site uses a session cookie to protect forms and display your application confirmation. It does not include advertising or analytics cookies.

Before sharing real personal data

This draft notice is for local testing. Use fictional details. Before public recruitment, techMoral must publish its approved privacy notice, contact for privacy requests, data retention policy and any required disclosures.
